# 0.2.0 重构与验收

目标：安装 App → Oproxy 登录 → 聊天 → 按需读取文档技能并生成完整文档，全程不要求用户安装其他软件。真实模型测试仅使用 Oproxy `gpt-6.1-sol`。

## 已实现

- 移除系统 Python 探测、pip 安装及任意模型代码执行。
- 把文档引擎从 MCP 服务拆出，直接生成不依赖 MCP 服务端口或 Relay。
- 随应用提供 Word/PDF/Excel/PPT 技能；MCP 也可通过 `get_document_skill` 读取技能。
- 原生 Word 样式/表格，中文 Chromium PDF，Excel 公式与数值，PPT 备注及按容量续页。
- 统一参数校验、生成排队、持久化回执、失败重试。
- 只处理明确的文档协议围栏，历史对话不自动执行，不通过工具名文本声称成功。

## 已验证

2026-11-10：`npm test` 5 项通过；`npm run test:desktop` 通过中文 PDF、等待流式结束、失败重试、DOM 变化不重复生成。模型无关的文件与界面测试不调用其他模型。
