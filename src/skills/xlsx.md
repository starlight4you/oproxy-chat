# Excel 工作簿技能
根据用户任务设计有意义的工作表、清晰列名、数据和汇总，不要把整篇报告塞进单列。区分输入、计算和假设。金额、数量、比例使用 JSON 数字，不使用带单位的数值字符串。
优先使用 sheets 数组。每项为 {"name":"工作表名称","columns":["列名"],"rows":[["文本",100,{"formula":"B2*2","result":200}]]}。公式不带等号，可提供 result 缓存；应用会独立重算公式并写入实际结果，不信任缓存。跨表公式正确引用工作表名。不要生成宏、外部工作簿引用或虚构真实业务数据；示例数据明确标注。
输出一个 oproxy_document 代码围栏，内容为 {"type":"xlsx","title":"标题","filename":"文件名.xlsx","sheets":[完整工作表]}。可用 content 补充说明，但实际数据必须放在工作表中。
可在每张工作表用 formats:["@","#,##0.00","0.0%"] 指定各列Excel数字格式，序号与columns对应。金额/百分比保留数字本身，展示单位写在表头；汇总与明细公式结果互相核对。不要将显示格式应用成数值字符串。

应用支持常见算术、SUM/AVERAGE/COUNT/ROUND/IF/SUMIF/SUMIFS等本地确定性计算及跨表引用。不要使用外部工作簿、结构化引用、网络函数、随机数或当前时间函数；未知函数或循环引用会作为校验失败返回。先自查所有单元格引用，再提交完整工作簿。
