# Word 文档技能
先理解目标读者、用途和用户要求，完成有实质内容的文稿。需要详细报告时给出摘要、论证、数据或明确标注的假设、可执行建议；不要用空泛提纲代替正文。
使用 content 提供标准 Markdown。渲染器会生成真正的 Word 标题、粗体、斜体、列表、超链接和表格，不需要去掉 Markdown，也不要把 Markdown 转义成可见的 \\n。
表格必须使用 Markdown 表头及分隔行。标题层级连贯，不重复文档总标题。不要伪造来源、统计数据或附件地址。
输出一个 oproxy_document 代码围栏，内容为单个 JSON 对象：{"type":"docx","title":"标题","filename":"文件名.docx","content":"完整 Markdown 正文，使用合法 JSON 换行转义"}。
代码围栏必须独占一行，与前面的进度说明之间留一个空行，结束围栏也独占一行，避免把JSON作为普通正文展示。
本科毕业论文等学术文稿在顶层增加 documentStyle:"thesis"。应用提供通用A4论文样式：独立封面、摘要、可更新目录、正文按章分页、宋体小四正文与黑体标题、首行缩进、页码。各院校要求不同，用户提供学校模板时以模板为准；没有模板时说明采用通用论文样式。content 中按顺序提供封面信息、## 摘要、## 目录、# 1 绪论等章节和# 参考文献，个人信息留空。不要编造目录页码，应用会生成原生目录域。文献和原文只能按实际核验结果引用。
